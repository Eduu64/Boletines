❓ Cómo conectar Discord (guía)

Opción A · Bot global (recomendado)

  1. En discord.com/developers/applications → New Application → pestaña Bot → Reset Token → copia el token.
  2. Pestaña OAuth2 → URL Generator: marca scope bot y permiso Send Messages; abre la URL generada para invitarlo a tu servidor.
  3. Activa el modo desarrollador (Ajustes → Avanzado), clic derecho en el canal → Copiar ID de canal.
  4. Pega el token y el ID de canal en Ajustes generales y guarda.

Opción B · Webhook por alerta

  1. En Discord: ajustes del canal → Integraciones → Webhooks → Nuevo webhook.
  2. Copia la URL (empieza por https://discord.com/api/webhooks/…).
  3. Pégala en la alerta (campo «Webhook de Discord») y pulsa «Probar».
